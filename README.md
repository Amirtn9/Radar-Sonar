# 🤖 Sonar Radar Bot

ربات تلگرام مانیتورینگ و مدیریت سرور با قابلیت:
- نمایش وضعیت CPU / RAM / Disk
- هشدار قطعی و افت کیفیت
- اتصال به چند سرور
- ارسال لاگ و آمار به تلگرام
- سیستم دسترسی ادمین
- نصب خودکار با یک دستور
