# 🚀 Radar Sonar Bot

ربات مانیتورینگ و مدیریت سرور با تلگرام  
پایدار، سبک، حرفه‌ای – مناسب برای VPS و سرورهای بین‌المللی

---

## ✨ امکانات

- مانیتور CPU، RAM، Disk، Uptime  
- هشدار قطعی و افت کیفیت  
- ارسال لاگ به تلگرام  
- مدیریت چند سرور همزمان  
- سیستم دسترسی ادمین  
- پایگاه داده SQLite  
- CLI کنترلی حرفه‌ای  

---

## ⚡ نصب سریع با یک دستور

wget https://raw.githubusercontent.com/Amirtn9/Radar-Sonar/main/install.sh
chmod +x install.sh
./install.sh


یا بعد از کلون:

chmod +x install.sh  
./install.sh
